# Дорожная карта проекта GTR1 (MVP Simulation)

## Цель
Реализация минимально жизнеспособной симуляции (MVP) первой информационно-сенсомоторной трансформации (GTR1) в режиме offline-replay (подача предзаписанного RGB-D датасета) на базе гибридного стека (C++ Core + Python ML, ZeroMQ, Protobuf).

## Критический путь и Зависимости
1. **Схемы данных блокируют всё:** Невозможно разрабатывать C++ Ядро или Python ML сервис без утвержденных Protobuf-схем для памяти (MP10-13) и сообщений IPC.
2. **База (MP10) блокирует MP12:** Синтаксический предиктор (SPL1) не может выполнять raycasting-тесты, пока нет воксельной сетки.
3. **ML (MP11) блокирует MP12:** Невозможно сформировать сплайсы (OPRN) между субъектом и объектами, пока CNN1 не отдаст список инвариантов.
4. **Среда отладки (Dashboard) критична для проверки:** Невозможно отлаживать асинхронные графы вслепую.

## Sprint 1: Фундамент (Data Models & IPC)
**Цель:** Заложить строгие структуры данных и контракты взаимодействия, определить классы в C++ и Protobuf, чтобы разблокировать параллельную разработку.

**Артефакты к созданию (Задачи 2.3, 3.4):**
1. `02_data_models/gtr1_structures.proto` — Схемы для VALI, MP10_Space, MP11_Object, MP12_OPRN, MP13_BLOM, MTV1_Goal.
2. `04_interfaces/ipc_messages.proto` — Обертки сообщений для ZeroMQ (входы сенсоров, результаты инференса ML, синхронизация).
3. `02_data_models/core_classes.puml` — Детальная UML-диаграмма классов для C++ с точными типами и методами.
4. C++ Заголовочные файлы:
   - `src/core/include/vali.hpp`
   - `src/core/include/mp10_space.hpp`
   - `src/core/include/mp11_object.hpp`
   - `src/core/include/mp12_oprn.hpp`
   - `src/core/include/mp13_blom.hpp`
   - `src/core/include/trl1_log.hpp`

---

## Sprint 2: Базовый каскад и Ingestion (DTR Часть 1)
**Цель:** Запуск пайплайна чтения датасетов, работа SLAM (SLGW) и формирование MP10 (Пространство).

**Артефакты к созданию:**
1. `07_infrastructure/dataset_player.cpp` — Модуль чтения TUM RGB-D/ROS Bag.
2. `src/operators/slgw_node.cpp` — Интеграция Visual SLAM, выдача позы (SE(3)).
3. `src/core/octomap_manager.cpp` — Построение и обновление воксельной сетки (OctoMap) в MP10.
4. `08_project_management/dashboard_mp10.md` (Спецификация 3D визуализатора).

---

## Sprint 3: ML Сервис и Объекты (DTR Часть 2)
**Цель:** Поднятие Python-микросервиса для детекции, связи по ZeroMQ, заполнение MP11.

**Артефакты к созданию:**
1. `src/ml_service/cnn1_worker.py` — Скрипт инференса YOLO/CLIP.
2. `src/ml_service/zmq_client.py` — Передача тензоров и Bounding Boxes через Protobuf.
3. `src/core/mp11_manager.cpp` — Логика C++ для пространственно-семантического слияния (разрешение коллизий инвариантов).

---

## Sprint 4: Синтаксис и Семантика (RTR и Замыкание)
**Цель:** Работа предикторов, формирование поведенческих графов, raycasting.

**Артефакты к созданию:**
1. `src/operators/spl1_splicer.cpp` — Вычисление $b$-векторов, геометрический тест включения к MP10.
2. `src/operators/prd1_predictor.cpp` — Формирование графов (MP13_BLOM), маршрутизация A*.
3. `src/core/mtv1_motivator.cpp` — Узел генерации целевых векторов.

---

## Sprint 5: Демонстрационный Стенд и Визуализация
**Цель:** Интеграция всего в отладочный UI для наглядной демонстрации.

**Артефакты к созданию:**
1. Dashboard UI (Web или ImGui) для визуализации MP10-MP13.
2. Интеграция механизма Trace ID для сквозного дебага.
