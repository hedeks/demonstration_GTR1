# План Тестирования (QA Master Plan)

## 14.1 Unit, Integration и Simulation тесты
- **Модульное тестирование (Unit):** Мы используем `GoogleTest` (C++) и `PyTest` (Python). 
  - *C++:* Жесткое покрытие бизнес-логики валентностей (`vali.hpp`) и слияния инвариантов (`mp11_manager.cpp`).
  - *Python:* Проверка корректности сериализации/десериализации Protobuf.
- **Интеграционное тестирование:** Запуск C++ ядра в связке с Python-воркером. Эмуляция потери связи с Python-сервисом на 2 секунды (проверка логики Exponential Backoff и таймаута в 200мс).
- **Симуляция (HIL/SIL):** Прогон всей системы (от SLGW до OP13) в режиме "чёрного ящика" через виртуальный датасет (сгенерированный через `PyBullet`).

## 14.2 Golden Datasets (Регрессия)
Мы фиксируем 3 эталонных сцены из академического TUM RGB-D (например, `fr1_desk`).
Для этих сцен мы сохраняем эталонный граф `MP13_BLOM`, который архитектура должна построить в конце пайплайна (файл `golden_fr1_desk.json`). 
Если после рефакторинга C++ кода граф меняется — это регрессия (Pipeline падает).

## 14.4 Матрица Трассируемости (Traceability Matrix)
Каждое архитектурное требование привязано к коду и тесту:

| ID Требования | Описание | Класс/Компонент | Название Тест-кейса |
|---|---|---|---|
| **REQ-01** | Инварианты ближе 0.5м с одинаковым классом сливаются | `MP11Manager` | `test_invariant_merge_spatial` |
| **REQ-02** | Raycast по препятствию в MP10 выдает COLLISION | `Spl1Splicer` | `test_splice_raycast_wall_hit` |
| **REQ-03** | Алгоритм A* обходит препятствие, создавая доп. узел | `Prd1Predictor` | `test_astar_routing_bypass` |
| **REQ-04** | Падение ML сервиса не вешает C++ ядро | `SlgwNode` | `test_zmq_timeout_recovery` |

## 14.3 Acceptance Criteria (Критерии Приемки)
MVP GTR1 считается завершенным и успешным, если:
1. Задержка DTR-каскада (кадр -> формирование MP11) не превышает 133 мс.
2. Прогон эталонного `Golden Dataset` проходит без ошибок.
3. Покрытие юнит-тестами (Code Coverage) для папки `src/core/` составляет не менее 90%.
4. Дашборд (Three.js) стабильно отрисовывает воксели на 30 FPS без утечек памяти (Memory Leaks).
