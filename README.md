# GTR1 MVP (Гативус Информационно-Сенсомоторный Уровень)

Добро пожаловать в репозиторий **GTR1 (Gativus Transformation 1)** — фундаментального ядра интеллектуального агента, реализующего теорию валентностей.

## Архитектурная Парадигма
GTR1 работает на базе встречных информационных потоков:
- **DTR (Прямой ход):** `Сенсор -> SLAM (MP10) -> YOLO/CLIP (CNN1) -> Инварианты (MP11)`. Превращает сырые пиксели в тождественные объекты 3D-мира.
- **RTR (Обратный ход):** `Мотиватор (MTV1) -> Предиктор (PRD1) -> Сплайсер (SPL1) -> Моторы (OP13)`. Превращает цель в поведенческий граф (MP13_BLOM) и физические векторы сближения ($b$-векторы).

## Технологический Стек
Проект реализован в рамках **Толстого Docker-контейнера**, объединяющего:
1. **Ядро (C++):** Высокопроизводительное управление графами памяти (MP10-13), алгоритм A*, OctoMap.
2. **ML Микросервис (Python):** Инференс YOLOv8 и CLIP.
3. **IPC (ZeroMQ + Protobuf):** Связь между C++ и Python (REQ/REP) с жестким таймаутом < 200ms.
