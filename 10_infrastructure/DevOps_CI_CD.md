# Платформа, Инфраструктура и Конфигурация (DevOps)

## 10.1 Целевая Платформа
- **ОС:** Ubuntu 22.04 LTS (Host и Container).
- **Аппаратное обеспечение:** Обязательно наличие GPU (NVIDIA CUDA 12.1+) для работы YOLO в реальном времени.
- **Среда:** Docker CE с модулем `nvidia-container-toolkit`.

## 10.2 Docker Архитектура
Для MVP используется монолитный "Fat Container" (`gativus-gtr1-mvp`), содержащий:
1. Скомпилированные C++ бинарники ядра.
2. Python 3.10 окружение с PyTorch и Ultralytics.
Это гарантирует отсутствие сетевых задержек TCP и проблем с версиями библиотек на хосте.

## 10.3 CI/CD Пайплайн
- **Build:** GitLab CI собирает C++ код через `CMake`, формирует Python окружение.
- **Test:** Запуск Unit-тестов и Golden Dataset.
- **Release:** Сборка финального Docker-образа и отправка в приватный Docker Registry.

## 11. Конфигурация (JSON Schema)
- Все настройки (NFR, тайм-ауты, FPS, пороги YOLO) вынесены в `config.json`. 
- При запуске `main.cpp` происходит валидация файла конфигурации с помощью `JSON Schema` (Strict Mode).
- Горячая перезагрузка (Hot-reload) для MVP не поддерживается. Для изменения порога детекции нужен рестарт ядра.

## 12. Алертинг и Мониторинг
- TraceLogger публикует логи с `Trace ID` уровня `INFO`, `WARN`, `ERROR` и `FATAL`.
- Появление уровня `FATAL` (например, падение ZeroMQ сокета больше 3 раз) останавливает контейнер.
