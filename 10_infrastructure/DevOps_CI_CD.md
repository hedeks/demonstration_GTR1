# Платформа, Инфраструктура и Конфигурация (DevOps)

## 10.1 Целевая Платформа
- **ОС:** Ubuntu 22.04 / 24.04 LTS (нативный Linux или WSL2).
- **Аппаратное обеспечение:** Поддержка GPU (NVIDIA CUDA 12.1+) для ускорения инференса YOLOv8. При отсутствии GPU поддерживается запуск на CPU.
- **Среда:** Нативная хост-система без контейнеризации (отказ от Docker в пользу прямого исполнения).

## 10.2 Архитектура Нативного Хоста
Для GTR1 используется прямое межпроцессное взаимодействие (IPC) на хосте:
1. Скомпилированное C++ ядро (`gtr1_main`).
2. Python 3.12 окружение (ML-воркер `cnn1_worker.py`, физический симулятор `pybullet_env.py`, WebSocket-мост `ws_bridge.py`).
Это гарантирует минимальные задержки передачи данных через IPC (ZeroMQ), нативный доступ к видеокарте и дисплею без проброса сокетов контейнера.

## 10.3 CI/CD Пайплайн
- **Build:** Сборка C++ кода через `CMake`, генерация Protobuf схем для C++ и Python.
- **Test:** Запуск набора GoogleTest (58 тестов) через `ctest` и Golden Dataset.
- **Run:** Оркестрация единым bash-скриптом `run_demo.sh`.

## 11. Конфигурация
- Все настройки (NFR, тайм-ауты, FPS, пороги YOLO) централизованы в конфигурации и аргументах запуска.
- Поддерживаются флаги запуска `--sim`, `--dataset`, `--gui`, `--headless`, `--emulated`, `--clean`.

## 12. Алертинг и Мониторинг
- TraceLogger публикует структурированные логи с `Trace ID` уровней `INFO`, `WARN`, `ERROR` и `FATAL`.
- Появление уровня `FATAL` аварийно останавливает процессы через `cleanup`-ловушку сигналов в оркестраторе.
